# Deletion inventory: what account deletion does to every column that can hold text.
#
# Rule: every column of a text, character, JSON, bytea, tsvector, XML or enum type
# (or an array, domain or composite type holding one, resolved recursively) in every
# table and materialized view a fresh install of the three migration tracks creates
# (server/drizzle, apps/auth/migrations, server/migrations), except the Drizzle
# migrator's own journal. server/test/deletion-inventory.test.ts applies
# all three tracks to an empty PostgreSQL and fails on any such column missing here,
# or listed here but gone. Classes:
#   deleted       account deletion removes the row
#   hidden        kept after deletion (until it expires, or for a stated purpose),
#                 never served to an AI or shown on a page
#   retained      kept with no link to any account, so deletion cannot remove it,
#                 and may hold personal data someone entered; the reason says how long
#   not-personal  holds nothing about a person
#
# schema.table | class | columns | reason
